# MANACO - Landing Page

Landing page de ejemplo para MANACO, empresa de calzado cómodo y funcional.

## Accesibilidad (a11y)

En esta sección se detallan las mejoras de accesibilidad implementadas:

- Se incluyó un **skip link** para que los usuarios puedan saltar directamente al contenido principal.
- Todos los elementos interactivos (enlaces y botón de menú hamburguesa) tienen **foco visible** para navegación con teclado.
- La navegación y todos los links son accesibles mediante **tabulación**, asegurando que la página pueda ser usada sin mouse.
- Las imágenes incluyen atributos **alt descriptivos**, aunque se usan placeholders, para indicar contenido visual.
- Se emplearon roles semánticos (`role="banner"`, `role="navigation"`, `role="main"`) y `aria-label` de forma prudente para mejorar la comprensión de la estructura por lectores de pantalla.
- Se probó el contraste de texto y elementos interactivos, asegurando legibilidad y usabilidad.

## SEO

Decisiones de SEO on-page implementadas:

- Se definió un **title único y descriptivo**: "MANACO — Calzado que impulsa tu paso".
- Se incluyó un **meta description** de 150-160 caracteres resumida sobre la marca y productos.
- Se añadieron etiquetas **Open Graph mínimas** (`og:title`, `og:description`, `og:image`) para optimización en redes sociales.
- Se respetó la **jerarquía de encabezados**: H1 único para hero, H2 para secciones, H3 para productos.
- Se utilizó HTML5 semántico y etiquetas apropiadas para mejorar la indexación por motores de búsqueda.
